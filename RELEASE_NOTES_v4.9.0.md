# StatusOS v4.9.0 - AI Conversation Memory

## Added
- Remembers the recent Command Center conversation across follow-up questions.
- Keeps the current artist and topic when later messages use words such as "he", "that", or "again".
- Reuses the selected artist context when the artist name is not repeated.
- Stores the latest 12 conversation turns locally.
- Adds a New Conversation button to clear context intentionally.

## Example
1. Ask: What should I say to Jesse about the deposit?
2. Follow with: When should I ask again?
3. StatusOS continues using Jesse and the deposit topic without asking for the details again.
