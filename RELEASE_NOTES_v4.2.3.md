# StatusOS v4.2.3 - Morning Routine Reliability

## Fixed
- Complete Morning Routine now records completion immediately.
- Morning completion is stored with a completion timestamp and appears in Success History and the Unified Timeline.
- The Morning button changes to “Morning Routine Completed,” matching Night Routine feedback.
- Morning action controls are no longer sticky or floating over content on mobile.
- Morning and Night buttons now use consistent labels and completed styling.
- Draft autosave no longer silently controls whether the Morning button can complete the routine.

No database migration is required.
